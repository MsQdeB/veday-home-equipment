# Veday Equipment Dashboard

Bản công khai (public) của **bảng so sánh báo giá thiết bị** cho căn hộ Veday Home (Đà Nẵng).

- `index.html` — trang giới thiệu (landing).
- `so-sanh-bao-gia-thiet-bi.html` — bảng so sánh (tự chứa, chạy offline, song ngữ VI/EN).

Trang có gắn `noindex` + `robots.txt` để **không bị công cụ tìm kiếm lập chỉ mục**.

Nguồn dữ liệu & báo giá gốc (PDF/Excel/ảnh) nằm trong repo **riêng tư** `veday-home-docs`.

> Lưu ý: mọi chỉnh sửa của người xem (chọn mua, số lượng, đánh giá) chỉ lưu trong trình duyệt của họ (localStorage), không sửa file này.
